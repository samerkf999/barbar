# Princess Eagle Booking

Mobile-first barber booking website using Python Flask, SQLite, vanilla JavaScript and CSS.

## Run
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

- Customer booking: `/`
- Owner dashboard: `/admin`
- Demo admin key: `princess-admin`

Data is stored in `princess_eagle.db`. Change the admin key with `PRINCESS_ADMIN_KEY`.
